# 3D 체스 — AI와 한 판

브라우저에서 바로 하는 3D 체스. 대리석 기물(금장식), 나무결 체스판, 그림자와 반사를 전부 코드로 만들었고,
AI 상대는 직접 짠 체스 엔진입니다. 설치할 것 없이 열면 됩니다.

**플레이:** https://sunlitkoreakorea.github.io/chess-3d/

## 기능
- 모든 체스 규칙: 캐슬링, 앙파상, 승진(퀸·룩·비숍·나이트 선택), 체크·체크메이트, 스테일메이트,
  3회 동형 반복, 50수 규칙, 기물 부족 무승부
- AI 5단계(입문 · 초급 · 중급 · 고급 · 마스터), 백/흑/랜덤 선택. AI는 웹 워커에서 계산해서 화면이 멈추지 않아요
- 기물 클릭 → 갈 수 있는 칸 표시 → 클릭으로 이동. 이동·잡기·캐슬링·승진 애니메이션, 잡힌 기물은 판 옆으로,
  체크메이트 당한 왕은 쓰러짐
- 무르기, 힌트(AI가 추천수 표시), 기권, 기보(SAN, 기물 그림 표기), 잡은 기물·기물 점수 차
- 시점: 백 / 흑 / 위에서 / 옆에서 + 마우스로 자유 회전·확대 (휴대폰은 터치)
- 효과음은 파일 없이 WebAudio로 합성. 화면이 느리면 해상도를 자동으로 낮춰요
- 폰·좁은 화면에서는 판 아래로 패널이 내려옵니다

## 내 컴퓨터에서 실행
ES 모듈을 쓰므로 파일을 더블클릭하지 말고 간단한 서버로 여세요.
```bash
python -m http.server 8766
```
→ http://localhost:8766/  (Windows는 `시작.bat` 더블클릭)

## 테스트
```bash
node --test
```
- `engine.test.js`: 표준 perft 값(시작 국면, Kiwipete, 앙파상·승진 포지션 등)과 SAN·종료 판정·반복 판정
- `search.test.js`: 한 수/두 수 메이트, 공짜 기물, 평가 대칭, 난이도별 시간, AI끼리 한 판

## 구조
| 파일 | 역할 |
|---|---|
| `engine.js` | 0x88 보드 규칙 엔진 (수 생성, 두기/되돌리기, FEN, SAN, 종료 판정) |
| `search.js` | 평가 함수 + 알파-베타 탐색(반복 심화, 치환표, 널무브, LMR, 정지 탐색) |
| `levels.js` · `ai.js` · `ai-worker.js` | 난이도 값, 화면 쪽 AI 창구, 워커 |
| `pieces.js` | 기물 모델링: 선반 가공 윤곽(LatheGeometry), 성가퀴, 왕관, 말 머리 스윕(갈기·귀·눈) |
| `textures.js` | 대리석·나무결·글자 질감을 캔버스로 생성 |
| `stage.js` | 체스판·조명·그림자, 이동 애니메이션, 하이라이트, 카메라 |
| `main.js` · `index.html` · `style.css` | 게임 진행과 화면 |
| `pieces.html` | 기물만 따로 돌려 보는 전시 페이지 |
| `vendor/` | three.js r170 (MIT) 와 필요한 애드온 |
